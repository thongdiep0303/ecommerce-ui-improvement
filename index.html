02 / JAVASCRIPT

Thực hành với Chrome Dino

Chrome DevTools cho phép quan sát và chạy JavaScript ngay trên trang đang mở. Trong bài mẫu, đối tượng Runner.instance_ được dùng để thao tác với trò chơi.

// Kiểm tra tốc độ hiện tại
Runner.instance_.currentSpeed;

// Thử tăng tốc độ
Runner.instance_.setSpeed(60);

// Thử điều chỉnh lực nhảy
Runner.instance_.setJumpVelocity(22);

Các lệnh phụ thuộc vào phiên bản trò chơi và môi trường trình duyệt. Hãy kiểm tra trực tiếp trước khi đưa ảnh kết quả vào báo cáo.

Quan sát giá trị ban đầu

Bài mẫu ghi tốc độ khoảng 6.8 và lực nhảy mặc định −10.

Điều chỉnh tốc độ

Thử mức 60 để xem sự thay đổi nhịp độ.

Điều chỉnh lực nhảy

Thử mức 22 rồi quan sát khả năng vượt chướng ngại vật.

Ghi nhận bằng chứng

Chụp màn hình Console kèm game, mô tả kết quả thực tế.

03 / CSS

Responsive không chỉ là thu nhỏ trang

Bố cục bài thực hành gốc gồm hai vùng LEFT (70%) và RIGHT (30%). Khi thay đổi viewport, media queries có thể xếp chồng hoặc ẩn các vùng này.

Thử các kích thước màn hình

LEFT 70%
RIGHT 30%

Hai vùng nằm cạnh nhau theo tỷ lệ 70% / 30%.

Media queries từ bài học

@media screen and (max-width: 768px) {
  .left, .right { width: 100%; }
}

@media screen and (min-width: 321px)
       and (max-width: 479px) {
  .right { display: none; }
}

@media print {
  .left { display: none; }
  .right { width: 100%; }
}
04 / HTML

Thẻ <picture> giúp chọn ảnh phù hợp

Ở bài gốc, các nguồn logo khác nhau được chọn dựa trên độ rộng viewport. Đây là ví dụ về art direction trong HTML.

≥ 1000pxẢnh dành cho màn hình lớn (logo UEH trong bài mẫu)
600–999pxẢnh dành cho màn hình vừa (logo CTD)
< 600pxẢnh dự phòng cho màn hình nhỏ (logo BIT)
Chế độ inCSS @media print thay đổi bố cục khi in hoặc xuất PDF
05 / TỔNG KẾT

Điều mình rút ra sau buổi học

Điểm thú vị là JavaScript và CSS giải quyết hai bài toán khác nhau: JavaScript tác động đến hành vi của ứng dụng, còn CSS media queries tác động đến cách giao diện trình bày theo từng môi trường. Khi kết hợp với DevTools, mình có thể kiểm thử và quan sát thay đổi nhanh hơn.

Bước thực hành tiếp theo: thử thiết kế trang sản phẩm thương mại điện tử responsive, có danh sách sản phẩm và bộ lọc được ẩn/hiện phù hợp trên màn hình nhỏ.
