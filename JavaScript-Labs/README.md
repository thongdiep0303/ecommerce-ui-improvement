## Cách chạy

1. Mở thư mục `JavaScript-Labs` bằng Visual Studio Code.
2. Dùng extension **Live Server** mở `index.html`.
3. Nhấn liên kết đến các Lab và kiểm tra trang tương ứng.
4. Mở Console (`F12`) để kiểm tra lỗi khi cần.

## Mục tiêu

- Nắm vững cú pháp và các đối tượng JavaScript cơ bản.
- Thực hành lựa chọn, chỉnh sửa DOM và xử lý các sự kiện.
- Sử dụng jQuery cho giao diện tương tác, animation và GET/JSON.

## Lưu ý trước khi nộp

- Kiểm tra tất cả liên kết HTML thực sự tồn tại.
- Bổ sung ảnh đại diện thật vào trang chủ (khi cần).
- Dùng ảnh chụp kết quả chạy của chính mình trong báo cáo Word.
- Đưa thư mục `JavaScript-Labs` vào repository cũ, không xóa bài đã nộp trước đó.
